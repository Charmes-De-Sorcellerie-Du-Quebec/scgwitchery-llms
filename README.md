## Service framework

- **Praxis:** Established workings without individual customization. Consultation is optional and separate.
- **Telos:** Adapted ritual work with targeted customization. Consultation included.
- **Gnosis:** Fully bespoke ritual construction. Consultation included.

The linked website pages govern current pricing, availability, booking requirements, and policies. No particular outcome is guaranteed.
